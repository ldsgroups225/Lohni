# Lohni reste gratuit et non commercial

Lohni dérive de PageLM, dont la licence (`LICENSE.md`, sections 3 et 4) interdit tout usage commercial sans accord de partage de revenus signé avec les auteurs, sous peine de résiliation immédiate. Nous décidons donc que Lohni reste gratuit, sans publicité, sans abonnement et sans partenariat payant ; la marque et l'interface sont conçues sur cette base.

## Conséquences

- Toute idée de revenu (abonnement, pass, publicité, offre payante aux écoles) commence par un accord écrit avec les auteurs de PageLM, avant tout lancement.
- Le crédit à PageLM reste visible dans « Moi », dans le README, dans la description du dépôt et sur tout support de présentation (section 6).
- Le code n'est publié nulle part ailleurs que dans le fork GitHub (section 2).
